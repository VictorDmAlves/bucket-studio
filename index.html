O que significa “autoajustar”?

1. Reagrupamento com menor corte

Busca aproximar imagens de buckets com batches incompletos, desde que o crop fique dentro do limite definido. Não estica as fotos.

2. Prévia antes de salvar

Os crops são propostas reversíveis; o original não é alterado. Revise no Crop Studio, especialmente rostos e mãos nas bordas.

Resumo da saída

Preciso exportar? Não, se você só deseja analisar o dataset. O OneTrainer pode utilizar os arquivos originais. Exporte o ZIP somente para aplicar os crops/redimensionamentos feitos aqui; este ZIP produz imagens para um cenário de resolução selecionado, não amostras duplicadas para todas as resoluções.
